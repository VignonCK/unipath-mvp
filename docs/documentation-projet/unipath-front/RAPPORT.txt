1. PRÉSENTATION GÉNÉRALE
--------------------------------------------------------------------------------

unipath-front est l'interface web (SPA) de la plateforme UniPath. Elle permet
aux candidats, à la commission, au DGES et aux administrateurs d'établissement
d'interagir avec le backend unipath-api.

L'application est organisée autour de deux modules métier pour les étudiants :
  - Module Concours (inscriptions aux concours universitaires MESRS)
  - Module Parcours académique (établissements privés, campagnes, inscriptions)

État actuel : application React complète, multi-rôles, connectée à l'API locale.

6. AUTHENTIFICATION FRONTEND
--------------------------------------------------------------------------------

  Mécanisme : JWT stocké dans localStorage (token + user)

  Flux :
    Inscription → message confirmation email → /login
    Login → saveAuth() → redirection selon rôle (getDefaultRoute)
    401 API → déconnexion automatique → /login
    Reset password → email → /reset-password?token=...

  Redirections par rôle :
    CANDIDAT/ETUDIANT     → /dashboard
    COMMISSION            → /commission (ou examinateur/controleur selon sousRole)
    DGES                  → /dashboard-dges
    ADMIN_ETABLISSEMENT   → /admin-etablissement/campagnes

  Changement mot de passe obligatoire :
    mustChangePassword → page dédiée avant accès au dashboard


7. INTÉGRATION API
--------------------------------------------------------------------------------

  Fichier central : src/services/api.js

  Services exposés :
    authService, candidatService, concoursService, inscriptionService,
    dossierService, commissionService, dgesService, campagneAdminService,
    campagneService, etablissementService, applicationService,
    inscriptionAcadService, preinscriptionEtablissementService,
    parcoursService, completionService, historyService, etc.

  Pattern :
    - JSON via request() avec Bearer token automatique
    - Multipart via fetch séparé pour uploads
    - PDF via téléchargement blob

  Configuration :
    VITE_API_URL=http://localhost:3001/api  (dans .env)

10. MODULES MÉTIER (VUE PRODUIT)
--------------------------------------------------------------------------------

  MODULE 1 — CONCOURS
    Public cible : candidats au BAC souhaitant s'inscrire aux concours MESRS
    Parcours     : Découverte → Inscription → Dépôt dossier → Suivi → Convocation
    Acteurs      : Candidat, Examinateur, Contrôleur, Commission, DGES

  MODULE 2 — PARCOURS ACADÉMIQUE
    Public cible : étudiants cherchant une inscription en école privée/supérieure
    Parcours     : Établissements → Candidature → Paiement → Documents →
                   Préinscription → Inscription → Relevé
    Acteurs      : Candidat, Admin établissement, Établissement

13. CONCLUSION
--------------------------------------------------------------------------------

Le frontend UniPath est une SPA mature couvrant l'ensemble des rôles et des deux
modules métier. L'interface est entièrement branchée sur l'API JWT locale.
Les principales dettes techniques concernent les reliquats Supabase, les paiements
mock et l'absence de refresh token.
