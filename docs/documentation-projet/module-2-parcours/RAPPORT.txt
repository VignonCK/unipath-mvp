1. VUE D'ENSEMBLE
--------------------------------------------------------------------------------

Le Module 2 « Parcours académique » est l'espace UniPath dédié aux étudiants
souhaitant s'inscrire dans une université ou école supérieure privée, et au
suivi de leur cursus une fois admis.

Sur la plateforme, il est accessible depuis le hub étudiant (/dashboard) sous
l'intitulé « Module 2 — Parcours académique ». Il couvre :
  - La découverte des établissements privés et de leurs filières
  - Les campagnes d'inscription annuelles
  - Le dépôt de candidature (dossier d'admission)
  - La préinscription et la décision de l'établissement
  - L'inscription académique effective
  - Le relevé de notes et le parcours universitaire


2. OBJECTIFS DU MODULE
--------------------------------------------------------------------------------

  - Offrir un catalogue des établissements privés et leurs filières
  - Permettre aux écoles de publier des campagnes d'inscription
  - Gérer le workflow de candidature en ligne (dossier + frais + documents)
  - Traiter les préinscriptions et décisions d'admission
  - Valider les quittances bancaires (droits d'inscription)
  - Suivre les inscriptions académiques et les notes par semestre
  - Produire le relevé de notes (consultation + PDF)

4. ENTITÉS DE DONNÉES
--------------------------------------------------------------------------------

  Etablissement
    Nom, type (PRIVE/PUBLIC), ville, adresse, email, logo

  Filiere
    Nom, code, niveau (Licence/Master), durée, établissement parent

  CampagneInscription
    Titre, année académique, dates ouverture/clôture, statut (BROUILLON/PUBLIEE/CLOTUREE)

  CampagneFiliere
    Filière liée à une campagne, frais de dossier, places, critères

  Application (candidature)
    Numéro, candidat, établissement, filière, niveau, statut :
      DRAFT → DOSSIER_FEES_PAID → PENDING_DOCUMENTS →
      READY_FOR_PREINSCRIPTION → FICHE_GENERATED

  ApplicationDocument
    Pièces uploadées par le candidat ou auto-remplies depuis le profil

  Payment / Receipt
    Paiement frais de dossier (mock) et quittance bancaire

  PreinscriptionEtablissement
    Demande formelle après candidature validée
    Statut : EN_ATTENTE | VALIDE | SOUS_RESERVE | REJETE

  InscriptionAcademique
    Inscription effective dans une filière pour une année académique
    Statut : EN_COURS | VALIDE | REDOUBLANT | ABANDONNE

  Note
    Notes par matière, semestre, crédits (CC, examen, moyenne)

  Diplome
    Diplôme obtenu (Licence/Master)

6. WORKFLOW MÉTIER (PARCOURS D'ADMISSION)
--------------------------------------------------------------------------------

  Étape 1 — Candidat : Candidature
    Choisit établissement + filière + niveau
    Paie les frais de dossier (mock)
    Upload les documents requis
    Finalise et envoie la candidature
    Statut → READY_FOR_PREINSCRIPTION → FICHE_GENERATED

  Étape 2 — Établissement : Examen
    Consulte la candidature et les pièces
    Crée une préinscription si le dossier est recevable

  Étape 3 — Établissement : Décision préinscription
    VALIDE     → candidat admis en préinscription
    REJETE     → candidature refusée (motif)
    SOUS_RESERVE → compléments demandés

  Étape 4 — Candidat : Quittance bancaire
    Si préinscription validée, upload la quittance des droits d'inscription

  Étape 5 — Établissement : Validation quittance
    Approuve ou rejette la quittance bancaire

  Étape 6 — Inscription académique
    Création automatique ou manuelle de l'inscription académique
    L'étudiant apparaît dans la liste « Étudiants »

  Étape 7 — Suivi de cursus
    Saisie des notes par semestre
    Consultation relevé de notes par l'étudiant

11. RELATION AVEC LE MODULE 1
--------------------------------------------------------------------------------

  Les deux modules partagent :
    - Le compte candidat et le dossier personnel (Mon compte)
    - Le système de notifications
    - L'authentification JWT

  Ils sont indépendants fonctionnellement :
    Module 1 = concours d'entrée (sélection compétitive)
    Module 2 = admission directe / campagne dans une école privée


12. POINTS FORTS
--------------------------------------------------------------------------------

  - Workflow candidature guidé étape par étape
  - Campagnes configurables par l'admin établissement
  - Exigences documentaires personnalisables par école
  - Chaîne complète candidature → préinscription → inscription → notes
  - Interface admin avec guide de parcours intégré


13. LIMITES CONNUES
--------------------------------------------------------------------------------

  - Paiements simulés (pas de gateway réel)
  - Pas de module emploi du temps / vie étudiante
  - Certaines tables (Note, InscriptionAcademique) peuvent être vides selon import
  - Filières admin via interface (pas d'API DGES dédiée filières)


14. CONCLUSION
--------------------------------------------------------------------------------

Le Module 2 est opérationnel pour le parcours d'admission dans les universités
privées : de la découverte d'une école à l'inscription académique et au relevé
de notes. Il complète le Module 1 en couvrant l'admission non concurrentielle
(campagne / candidature directe) plutôt que le concours.
